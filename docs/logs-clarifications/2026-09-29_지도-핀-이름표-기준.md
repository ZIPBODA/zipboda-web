## 3. 원래 지시
- 청약 > 지도 페이지에서 지도에 표출되는 각 청약들이 현재보다 더 확대되었을 때 핀으로 표시되며, 이 전까지는 X건 으로 표출되게 할 것
- 추가로 확대를 했을 경우 단순히 핀으로 표출되는 것이 아닌 현재 청약을 select 했을 때와 같이 표시되는 청약 이름을 표출할 것

## 4. 모호한 부분
- "현재보다 더 확대" — 핀으로 바뀌는 확대 단계의 수치가 없다(당시 6단계, 축척 약 500m).
- "추가로 확대를 했을 경우" — 핀이 나올 때 이름표도 함께인지, 핀보다 한 단계 더 확대해야 이름표가 붙는지 두 가지로 읽힌다.
- 모든 핀에 선택 상태와 같은 이름표가 붙으면 선택한 청약을 구분할 수단이 사라진다.

## 5. 에이전트 질문
1. 한 건짜리를 배지 대신 핀으로 바꿀 확대 단계는? (4단계·100m / 5단계·250m / 3단계·50m)
2. 이름표는 언제부터? (핀과 함께 / 핀보다 한 단계 더 확대 시)
3. 선택한 청약 구분은? (선택만 노란색 / 전부 노란색)

## 6. 사용자 응답
1. 5단계 · 약 250m
2. 핀이 나올 때 함께
3. 선택만 노란색

## 7. 확정된 규칙
- `MAP_SINGLE_PIN_LEVEL = 5`. 6단계 이상에서는 한 건도 `1건` 배지, 5단계 이하에서 한 건짜리는 핀이다. 여러 건이 겹친 묶음은 갈라질 때까지 배지로 남는다.
- 지도에 핀으로 보이는 청약에는 모두 이름표를 단다. 이름 없는 핀 단계는 따로 두지 않는다.
- 이름표는 흰 배경·진한 글씨, 선택한 청약만 브랜드 색 배경이며 다른 이름표보다 위에 놓인다.
- 이름표를 누르는 것은 그 핀을 누르는 것과 같다.
