## 3. 원래 지시
- 청약 > 지도 페이지의 '내 위치'를 눌렀을 때 "현재 위치로 이동했습니다." 안내가 사라지지 않는 이슈 수정
- 내 위치를 눌렀을 때 어디인지 명확한 표시 기능 추가

## 4. 모호한 부분
- 안내가 얼마 뒤에 사라져야 하는지, 실패 안내도 같은지.
- "명확한 표시"의 모양(점만 / 오차 반경까지).
- 멀리서 보고 있을 때 확대까지 할지(당시: 중심만 옮김).

## 5. 에이전트 질문
1. 위치 표시: 파란 점 + 정확도 원 / 파란 점만
2. 확대: 동네 수준(5단계)까지 확대 / 배율 그대로
3. 안내 문구: 성공 3초·실패 6초 / 모두 3초 / 실패는 닫기 전까지

## 6. 사용자 응답
1. 파란 점 + 정확도 원
2. 동네 수준까지 확대
3. 성공 3초·실패 6초

## 7. 확정된 규칙
- 내 위치는 흰 테두리의 정보색(`status-info`) 점과, 기기가 알려준 오차 반경만큼의 옅은 파란 원으로 표시한다. 오차를 모르면 점만 찍는다. 점은 청약 핀·이름표보다 위에 둔다. 원의 투명도는 사용자가 정한 예외다(배경 불투명 원칙 R12).
- 내 위치로 옮길 때 5단계(약 250m)보다 멀리 보고 있으면 5단계까지 확대한다. 더 가까이 보고 있으면 배율을 유지한다. 패널·툴바가 가린 폭을 비켜 남은 화면 가운데에 둔다.
- 안내 문구는 성공 3초, 실패 6초 뒤 사라진다. 사용자가 지도를 끌기 시작하면 그 전에도 사라진다.
